# Editorial Handbook

## Voice

Digital Observatory should sound:

- curious
- precise
- calm
- technical when useful
- accessible to non-specialists
- occasionally playful
- skeptical of hype

Avoid:

- artificial urgency
- exaggerated claims
- unexplained jargon
- “this changes everything”
- manufactured certainty

## Article structure

### 1. Headline

Specific and informative.

Good:

> A Small Python Package Just Became One of GitHub's Fastest-Growing Projects

Avoid:

> THIS CRAZY TOOL IS TAKING OVER THE INTERNET!!!

### 2. The observation

State the measurable change in one or two sentences.

### 3. The data

Show the relevant chart/table and time window.

### 4. What changed?

List releases, announcements, discussions, or other documented events.

### 5. Why it is interesting

Explain context, not hype.

### 6. What we cannot conclude

Explicitly state limitations.

### 7. Method

Explain calculations and source selection.

### 8. Sources

Link primary sources wherever possible.

### 9. Update timestamp

Always show when live data was last collected.

## Standard language

Prefer:

- “The data shows...”
- “We observed...”
- “The increase coincided with...”
- “One possible explanation is...”
- “Public data cannot establish...”
- “According to...”

Avoid:

- “This proves...”
- “Everyone is using...”
- “The industry has decided...”
- “This will definitely...”

## Article types

- **Observation** — one meaningful change.
- **Radar** — a collection of things worth watching.
- **Deep Dive** — detailed investigation.
- **Experiment** — reproducible test.
- **Benchmark** — defined comparison.
- **Census** — periodic ecosystem snapshot.
- **Timeline** — historical evolution.
- **Archive** — software/internet archaeology.
- **Weird** — unusual but well-sourced discoveries.

## Publishing checklist

- [ ] Every important factual claim has a source.
- [ ] Time window is explicit.
- [ ] Source timestamps are available.
- [ ] Derived metrics have formulas.
- [ ] Correlation is not described as causation.
- [ ] Uncertainty is disclosed.
- [ ] Primary sources are preferred.
- [ ] Copyright and source terms are respected.
- [ ] Charts have labels and units.
- [ ] Mobile presentation is readable.
